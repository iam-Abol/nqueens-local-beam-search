Local Beam Search, Diversity, and Information Sharing in N-Queens

An Empirical and Theoretical Investigation

GitHub Repository: https://github.com/iam-Abol/nqueens-local-beam-search

1. Executive Summary & Problem Formulation

1.1 Central Investigation

In heuristic and local search, maintaining multiple candidate solutions is a classic paradigm for escaping local minima and exploring parallel regions of a search space. This investigation addresses the central question posed by the assignment:

Under a fixed evaluation budget, does maintaining several candidate states (kkk boards) and sharing information between them increase the probability of finding a conflict-free board? When does cooperation help, and when does it destroy useful diversity?

We evaluate five local search paradigms on the NNN-Queens problem across board sizes N∈{8,32,100}N \in \{8, 32, 100\}N∈{8,32,100}, beam widths k∈{1,2,4,8,16}k \in \{1, 2, 4, 8, 16\}k∈{1,2,4,8,16}, and budgets B∈{2×103,2×104,105}B \in \{2\times 10^3, 2\times 10^4, 10^5\}B∈{2×10​3​​,2×10​4​​,10​5​​} across 75 independent, matched pseudo-random evaluation seeds:

  1. Method A (One-State Local Search): Tracks a single board (k=1k=1k=1), taking the lowest-energy neighbor from mmm sampled moves (best-neighbor walk).
  2. Method B (Independent Multi-Start): Tracks kkk independent trajectories with zero communication, each receiving an equal partition of the evaluation budget (B/kB/kB/k).
  3. Method C (Greedy Local Beam Search): Expands all kkk states, pools all k×mk \times mk×m candidate moves, deduplicates exact boards, and greedily selects the globally best kkk states.
  4. Method D (Stochastic Local Beam Search): Pools and deduplicates successors, drawing kkk states without replacement via a Boltzmann distribution with calibrated temperature τ=0.5\tau = 0.5τ=0.5.
  5. Method E (Diversity-Aware Beam Search): Enhances Method D with a normalized Hamming distance rejection threshold dmin=0.10d_{\min} = 0.10d​min​​=0.10 to prevent clone takeover.
  6. Baseline (Random-Restart Strict Hill Climbing): Tracks a single state with strict uphill rejection (Δ>0\Delta > 0Δ>0 only), triggering a random restart after 10 consecutive stagnant steps.

2. Experimental Methodology & Calibration

2.1 Pilot Study & Parameter Freezing

To prevent test-set bias (p-hacking), five dedicated pilot seeds (1001–1005) were evaluated and permanently frozen prior to benchmark execution:

  • Temperature Calibration (τ\tauτ): We tested τ∈{0.5,1.0,2.0,5.0}\tau \in \{0.5, 1.0, 2.0, 5.0\}τ∈{0.5,1.0,2.0,5.0} on N=32,k=4,B=10,000N=32, k=4, B=10,000N=32,k=4,B=10,000. Higher temperatures injected excessive noise (mean final energy for τ=5.0\tau=5.0τ=5.0 was 13.213.213.2), whereas τ=0.5\tau = 0.5τ=0.5 preserved low-energy bias while enabling non-greedy exploration (mean energy 2.22.22.2). We froze τ=0.5\tau = 0.5τ=0.5.
  • Budget Calibration (BBB): The handout's starting grid {103,104,105}\{10^3, 10^4, 10^5\}{10​3​​,10​4​​,10​5​​} was calibrated to prevent saturation (100%100\%100% success in 10 steps) or total failure (0%0\%0% everywhere):
    • N = 8 \implies B = 2,000 (separates beam search from single-state).
    • N = 32 \implies B = 20,000 (captures the phase transition where beam search breaks through plateaus).
    • N = 100 \implies B = 100,000 (allows deep exploration in sub-second runtime).
  • Evaluation Seeds: 75 independent pseudo-random seeds (2001–2075) were generated via np.random.SeedSequence and isolated from the pilot seeds.

2.2 Successor Sampling & Budget Accounting

  • Neighborhood size mmm: For N=8N = 8N=8, all N(N−1)=56N(N-1) = 56N(N−1)=56 moves are evaluated. For N>8N > 8N>8, m=min(2N,N(N−1))m = \min(2N, N(N-1))m=min(2N,N(N−1)) distinct moves are sampled uniformly without replacement via an exact flat-index bijection.
  • Accounting: Initial scoring of a new board costs 1 evaluation; each proposed child scored via move_delta costs 1 evaluation. Read-only checks and validation consume zero budget units. Terminal partial generations are allocated round-robin across parents, rotating the starting parent index each generation.

5. Answers to Written Questions Q1–Q9

Q1. Parallel Workers vs. Beam Width

  • Difference: Distributing one board across 8 CPU workers divides the evaluation of the N(N−1)N(N-1)N(N−1) moves of a single state. The search space trajectory remains strictly sequential (k=1k=1k=1), following a single path. In contrast, a width-8 beam search retains 8 distinct board configurations simultaneously, exploring 8 different search trajectories.
  • Single Core Execution: Width-8 beam search can run sequentially on a single CPU core. In our implementation, a single process maintains the population of k=8k=8k=8 states, evaluating candidate moves in sequential batches without multiprocessing overhead.

Q2. Pooling Children in Beam Search vs. Multi-Start

  • Mechanics: In Independent Multi-Start (B), each trajectory selects only from its own proposed children. In Greedy Beam Search (C), children from all kkk parents are merged into a unified candidate pool.
  • When Pooling Helps: When one parent discovers an exceptionally promising descent direction, pooling allows the beam to allocate multiple winning slots to that parent's descendants, focusing computational effort where progress is fastest.
  • When Pooling Hurts (Exercise B): As proven in Exercise B, if one parent produces slightly better immediate children (E=1E=1E=1) while another produces slightly worse children (E=2E=2E=2) that lead directly to a global optimum (E=0E=0E=0), pooling ruthlessly eliminates the second lineage, trapping the entire search population in a dead end.

Q4. Duplicates, Near-Duplicates, and Common Ancestry

  • Exact Duplicates: Structurally identical configurations (qi=qjq_i = q_jq​i​​=q​j​​). Handled in O(N)O(N)O(N) via hash sets.
  • Near-Duplicates: States differing by only 1 or 2 queen positions (dH(qi,qj)≤2d_H(q_i, q_j) \le 2d​H​​(q​i​​,q​j​​)≤2). They belong to the identical local basin of attraction.
  • Common Ancestry: States that originated from the same initial random seed board.
  • Why Deduplication is Insufficient: Exact deduplication only removes identical boards. If parent PPP produces 10 children that each move a different queen to row 0, all 10 boards are structurally unique, yet they are near-duplicates sharing 100% common ancestry. Deduplication retains all 10, allowing that single lineage to monopolize the beam and causing complete diversity collapse.

Q9. Evidence for Genuine Cooperation vs. "More Work"

6. Conclusion

This empirical study demonstrates that local beam search provides a decisive advantage over single-state and multi-start search on complex combinatorial landscapes, but only when beam width is carefully balanced (k=4k=4k=4).

  1. When beam width is too large (k=16k=16k=16), search depth is starved under fixed budgets.
  2. When diversity is artificially forced via strict distance gates (Method E), search performance collapses by preventing local exploitation.
  3. Natural diversity collapse in Greedy Beam Search (Method C) is not necessarily a bug: it represents the algorithm concentrating search bandwidth within the most promising basin of attraction to achieve global solutions.
